# Installing Vurvey for Claude

There is one install path now, and it lives in the [README](../README.md#install).

The short version: copy the connector address from **Workspace settings**, **Connected apps** in
Vurvey, add it to your Claude client, and approve it in the browser. Nothing to download, no
binary, no package manager.

This page used to describe installing the `vurvey` CLI and pointing a client at it over stdio. That
is no longer how a customer connects Claude to Vurvey, and every command that was on this page has
been removed rather than left to rot. The CLI still exists as the staff and local-development path,
and what remains true about it is in
[Staff and local development](../README.md#staff-and-local-development).
